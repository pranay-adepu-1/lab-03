🎓 Viva Questions & Answers

1. Query parameter vs path parameter?
Path Parameter: Identifies a specific resource hierarchically within the URL (e.g., /books/5 identifies book with ID 5).
Query Parameter: Used to filter, sort, search, or paginate a collection without altering the identity of the resource (e.g., /books?search_q=Clean&order_by=price).

2. What does stateless mean?
In REST architecture, statelessness means each client request must contain all the information necessary for the server to process it. The server does not store any client session context between requests, enabling high horizontal scalability and reliability.

3. Which status code for bad input vs a missing record?
Bad Input: 400 Bad Request (e.g., missing mandatory title/author, non-numeric price, or negative pagination limits).
Missing Record: 404 Not Found (e.g., querying or modifying an ID that does not exist in the database).
